3. **直播源清单 (`*.m3u`)**：央视、卫视精选 IPv4/IPv6 列表自建分发。
4. **国内直接访问**：纯 HTTP 80 端口，无 SNI 阻断，无 SSL 握手延迟，全国非代理设备秒加载。
